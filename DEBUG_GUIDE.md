## 📋 Как отладить проблему

### Шаг 1: Включите вывод логов
В IDE откройте `Debug Console` (или используйте `flutter logs`)

### Шаг 2: Проверьте логи при загрузке видео
Ищите эти сообщения:
```
PlayerScreen: Opening media with URL: https://...
StreamService: Got muxed stream for {videoId}
PlayerScreen: Media opened successfully
```

### Шаг 3: Интерпретируйте логи

| Лог | Значение |
|-----|----------|
| `PlayerScreen: Opening media with URL:` | Начало загрузки URL |
| `StreamService: Got muxed stream` | ✅ Успешно получен основной поток |
| `StreamService: Got HLS stream` | ⚠️ Используется резервный HLS поток |
| `StreamService: Got stream via alt client` | ⚠️ Используется альтернативный клиент |
| `PlayerScreen: Media opened successfully` | ✅ Медиа открыто в плеере |
| `PlayerScreen: Error loading video:` | ❌ Ошибка при загрузке |
| `PlayerScreen: Player error:` | ❌ Ошибка при воспроизведении |

### Шаг 4: Общие решения

1. **Если видео не загружается вообще:**
   - Проверьте интернет соединение
   - Попробуйте открыть видео в браузере через кнопку "Open in YouTube"
   - Проверьте, доступно ли видео в вашем регионе

2. **Если загружается, но не воспроизводится:**
   - Это может быть проблема с медиа-фреймворком
   - Попробуйте перезагрузить приложение
   - Очистите кэш: `flutter clean`

3. **Если приложение зависает при загрузке:**
   - Таймаут установлен на 20 секунд
   - Если зависает дольше, значит проблема с интернетом или YouTube API

## 📱 Тестирование на разных платформах

### Android
- Нужно обновить `targetSdk` в `android/app/build.gradle`
- Убедитесь, что есть доступ в интернет в `AndroidManifest.xml`

### iOS
- Может потребоваться обновить `Podfile`
- Убедитесь в наличии доступа в интернет в `Info.plist`

### Web
- YouTube может блокировать некоторые запросы с веб-платформы
- Может потребоваться специальная конфигурация CORS

## 🚀 Производительность

### Кэширование URL (StreamService)
- **30 минут** - оптимальное время кэширования
- YouTube URLs обычно действуют 4-6 часов, но могут измениться раньше
- Если URL истёкнет - автоматически получится новый

### Таймауты
- **20 секунд** на получение потока - достаточно для стабильного соединения
- Если интернет медленный (< 1 Mbps), может потребоваться увеличить до 30 сек
